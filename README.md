# Storly Next.js Preview

Marketing preview for Storly – Multipurpose eCommerce Next.js Template. Based on the requested Brandly preview layout, with 22 home screenshots, product detail previews, inner-page galleries and motion.

Edit `src/` HTML/CSS/JavaScript. Run `npm run build`; serve `public/`. Vercel is configured automatically. Screenshot bundles in `assets/` are decoded losslessly at build time.

This repository contains the showcase page, not the full eCommerce application.
